# Reflow · web app

A study planner that bends when your day does, with Avi, your study buddy.
Designed by Aman Verma (Interaction Design).

This folder is the ready-to-host build: a static, installable web app (PWA).
- No build step needed. On Vercel choose Framework Preset: **Other**, and leave the build and output settings empty.
- Data is saved on the device (localStorage). Works offline after the first visit.
- Install: open the link on a phone → browser menu → **Add to Home Screen**.
